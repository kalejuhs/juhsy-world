모델 및 벤치마크 상세

벤치마크 방식

에너지 드리프트는 |E(t) - E₀| / |E₀|이며, CPU/GPU별 초기 에너지를 기준으로 별도 Worker에서 시뮬레이션 시간 0.1마다 측정합니다. 계산기 step 시간은 batch 종단 간 처리량입니다. CPU에는 Worker 왕복/상태 전달이, GPU에는 비동기 readback이 포함됩니다. 벤치마크 중에는 두 씬의 렌더를 멈추고 지원되는 입자 수를 기본 4,096개까지 순회하며, 8,192개를 선택하면 stress count를 추가합니다. pilot으로 같은 step 묶음을 약 12ms에 맞추고, 큰 count는 표본 수를 100회에서 최소 25회까지 줄입니다. 준비/워밍업 시간은 별도 표시합니다. CPU 적분 시간은 Worker 안에서 재고, GPU 적분 시간은 지원 브라우저에서 timer query로만 측정합니다. 미지원이면 GPU 계산 전용 시간은 추정하지 않습니다.
