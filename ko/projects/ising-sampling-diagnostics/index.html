How do samplers shape the low-temperature Ising curve?

저온과 임계 영역에서 평균 |m|을 비교합니다. 각 온도에서 두 알고리즘은 같은 초기 격자로 시작하고 업데이트 난수 흐름은 서로 독립적입니다.

고정 난수 시드 · 260102

Mean |m| vs temperature

체인(chain)은 샘플러를 한 번 실행해 얻는 상태의 연속입니다. 각 온도에서 replica(독립 실행) 4쌍은 두 알고리즘에 같은 초기 격자를 사용합니다. 오차 막대는 반복 실행별 평균 간 표준오차 1개입니다 (평균의 표준편차 / √4).

곡선 평균은 워밍업 뒤 25,000회 측정한 값으로 계산합니다. 처음 10,000회는 워밍업으로 제외합니다. 진단은 replica마다 signed m을 247회 표본화합니다 (101회마다).

각 온도 점은 별도 seed로 실행한 결과이며, 점을 잇는 선은 시각적 안내입니다.

01 / LOCAL DYNAMICS

각 격자점은 행 우선 순서로 방문하며 50% 확률로 스핀 뒤집기를 제안합니다. 제안된 뒤집기는 Metropolis 확률로 수락됩니다. 큰 스핀 영역이 형성되면 local 업데이트의 혼합이 느려질 수 있습니다.

02 / CLUSTER DYNAMICS

h = 0, k_B = 1에서 Wolff는 같은 스핀의 cluster를 결합 확률 1 − exp(−2J/T)로 성장시킨 뒤 cluster 전체를 뒤집습니다.

03 / DIAGNOSTICS

Rank-normalized split R-hat, τ, Bulk/Tail ESS는 signed m과 |m|을 따로 계산합니다. |m|이 상수이면 진단할 수 없습니다. 어느 관측량이든 휴리스틱 기준은 R-hat < 1.01, 전체 Bulk/Tail ESS ≥ 400 (replica 4개 기준)입니다. 기준 통과가 평형을 증명하지는 않습니다.
