Model and benchmark details

BENCHMARK METHOD

Energy drift is |E(t) - E₀| / |E₀|, sampled every 0.1 simulation-time units in a separate Worker with independent CPU/GPU baselines. Solver step timings are end-to-end batch throughput: CPU includes Worker messaging/state transfer, and GPU includes asynchronous readback. Run benchmark pauses both scene render loops and sweeps supported particle counts through 4,096; it also includes 8,192 when that count is selected. It pilot-calibrates equal step batches toward 12 ms and workload-scales samples from 100 down to 25 for the largest counts. Setup and warm-up are reported separately. CPU compute time is measured inside the Worker; GPU compute-only time uses WebGL timer queries when supported. GPU compute timing is otherwise unavailable, not estimated.

PHYSICAL MODEL

Truncated Plummer-like initial cluster · total mass = 1 · G = 1 · initial virial ratio = 1 · no walls or collision bounce. Softened Newton gravity · velocity Verlet. CPU uses Float64; GPU uses Float32. Some particles may escape through gravitational encounters.
